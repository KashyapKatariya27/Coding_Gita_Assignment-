## Topics Covered

- What JavaScript is, its creator, history, and original name
- JavaScript vs Java
- Interpreted vs compiled, and JIT compilation
- JavaScript engines (V8, SpiderMonkey, JavaScriptCore)
- Dynamic typing and case sensitivity
- Static vs dynamic websites
- Frontend vs Backend (restaurant analogy)
- Node.js and ECMAScript
- Events, DOM manipulation, and `<script>` usage

## How to Run the Code Examples

The code answers in `SectionE.md` and `SectionF.md` are HTML + JavaScript programs.

1. Copy the code into a file, for example `index.html`.
2. Open it with the **Live Server** extension in VS Code, or double-click the file to open it in a browser.
3. Click the button on the page to see the output.
4. Press `F12` to open the browser console and check `console.log` messages.
