## How to run

Run a file from this folder with Python. For example:

```bash
python topic_01_basic_if.py
```

The answers in each of Topics 1–9 run consecutively and ask for each question's input in order. Follow the `Q` number shown in each prompt and enter the values separated as requested. Topic 10 prints the predicted answers and execution-flow notes. `match-case` requires Python 3.10 or later.

The programs calculate results from entered values rather than printing the assignment's test answers as fixed results. Input is expected in the format described by the corresponding question (for example, a numeric value or a space-separated name as indicated).
